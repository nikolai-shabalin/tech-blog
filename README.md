# HTML/CSS/JS/ALLY - Технический блог о фронтенд-разработке

Экспертный блог о современных веб-технологиях, построенный на [Astro](https://astro.build/).

## 🎯 О проекте
Этот блог посвящён профессиональному изучению фронтенд-разработки с акцентом на:

- **CSS**: современные подходы к вёрстке, жидкая типографика, логические свойства, адаптивный дизайн
- **JavaScript**: новые возможности языка, лучшие практики, производительность
- **Доступность (A11Y)**: принципы инклюзивного дизайна, WCAG стандарты, практические рекомендации
- **Веб-производительность**: оптимизация, инструменты разработчика, метрики

## 📚 Структура контента
### Основные разделы
- **CSS** - глубокий разбор каскадных таблиц стилей
- **JavaScript** - современные возможности языка
- **Доступность (A11Y)** - принципы инклюзивного веба
- **Дайджесты** - еженедельные обзоры новостей фронтенда

## ✨ Особенности блога
- 🎨 **Минималистичный дизайн** - фокус на контенте без отвлекающих элементов
- ⚡ **100/100 Lighthouse производительность** - оптимизирован для быстрой загрузки
- 🔍 **SEO-оптимизация** - канонические URL, OpenGraph данные, структурированная разметка
- 🗺️ **Автоматический Sitemap** - для лучшей индексации поисковиками
- 📰 **RSS Feed** - подписка на новые статьи
- 📝 **Markdown & MDX** - удобное написание контента с интерактивными элементами
- 🦊 **Персонализация** - талисман Фронти с мотивирующими сообщениями
- 📱 **Адаптивность** - отличное отображение на всех устройствах
- ♿ **Доступность** - соответствует стандартам WCAG
